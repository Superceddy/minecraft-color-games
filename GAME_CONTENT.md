# Spielinhalte – Minecraft Color Games v0.7.0

## Guess the Block: vollständige Vanilla-Liste aus Java 26.3

Die Blockliste wird aus dem versionierten Vanilla-Registry-Datensatz geladen. Java 26.3 enthält **1.286 Blocktypen**. Blockstates wie Ausrichtung, geöffnete Türen oder Wasserstände sind keine eigenen Einträge. Die früher hier aufgeführte Auswahl von 158 Blöcken ist nicht mehr die vollständige Spielauswahl.

Quelle: [mj41/mc26-data – Branch mc-26.3](https://github.com/mj41/mc26-data/tree/mc-26.3). Texturen werden versionsgebunden von mcasset.cloud geladen. Die Durchschnittsfarbe wird – wenn der Browser die Textur auslesen darf – direkt aus der flachen Textur berechnet.
